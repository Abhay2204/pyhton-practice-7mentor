# 10. Real-World Mini-Projects & Scenarios

## 📌 Overview
Applying Python core data structures (`list`, `set`, `dict`, `tuple`) to solve practical real-world scenario problems.

---

## 🔑 Scenario Highlights

### 1. Vendor Stock & Buyer Basket Isolation (`newspaper_seller.py`)
Demonstrates isolating inventory state from customer cart states using `.copy()` to avoid unintended side effects.

### 2. Student Roll Number Management (`ssmv_school.py`)
Demonstrates generating sequence ranges using `set(range(1, N+1))` and managing roll numbers (e.g. deletions/removals) cleanly.

### 3. Pune Colleges NAAC Grade Tracker (`pune_colleges_record.py`)
Combines list operations (`.index()`, `.pop()`, `.insert()`) with dictionary generation using `zip()` to track college rankings and NAAC grades.
